# 人物桌宠

面向 Windows 10/11 x64 的透明桌面宠物。人物会在桌面自主爬行，识别窗口、任务栏和桌面图标，并能被拖到窗口边缘停留或攀附。

## 功能

- 自主爬行、待机、拖拽、下落和落地动画
- 避让应用窗口、任务栏和桌面图标
- 拖到窗口顶部时坐在窗口上
- 拖到窗口侧边时攀在窗口壁上
- 拖到窗口底边时悬挂
- 被依附的窗口关闭或最小化后自然掉落
- 右键选择“叫爸爸”或“说我错了”，人物跪下并使用 Windows 中文语音
- 粉色对话气泡自动避开人物脸部
- “原地休息”冻结当前动作，再次选择后恢复
- 支持 100%–200% 桌宠大小和语音音量调节
- 正式安装版默认启用当前用户开机启动

## 安装

下载或自行构建 `Person-Desktop-Pet-Setup-1.0.0-x64.exe`，双击后按安装向导完成安装。

安装器没有商业代码签名证书，Windows 可能提示“未知发布者”。

## 使用

- 鼠标左键按住人物可拖动桌宠。
- 将人物松开在窗口顶部、侧边或底边，可触发不同停留姿势。
- 鼠标右键打开互动菜单，可控制语音、休息、自主活动、大小、音量及开机启动。
- 关闭桌宠依附的窗口后，人物会掉落并重新回到桌面活动。

## 本地开发

需要 Node.js 和 npm。

```powershell
npm install
npm start
```

运行测试：

```powershell
npm test
```

构建 Windows x64 NSIS 安装程序：

```powershell
npm run build:win:x64
```

构建结果位于 `dist/`。

## 隐私与素材

- 正式安装包只包含运行代码、动作清单和 9 张运行图集。
- 安装包不包含原始人物照片、动作原始帧、生成中间文件或动作元数据。
- 源码仓库包含获准使用的人物参考照片与派生动作素材，用于验证身份一致性和重新打包动画。
